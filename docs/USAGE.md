# Utilisation

Le skill se déclenche quand la demande porte sur une page, une maquette ou un site web. Vous pouvez aussi le nommer.

## Exemples de demandes

- « Construis la page d'accueil de mon outil en suivant le skill site-web-sans-look-ia. »
- « Fais-moi 3 directions pour la page de mon jeu, avec le skill site-web-sans-look-ia. »
- « Revois ce site : il fait trop généré par IA. » (mode revue)

## Déroulé

1. **Cadrage** : Claude écrit une note de cadrage (sujet, publics, tâche n°1 du visiteur, ton, matière réelle disponible). Donnez-lui vos captures, logos et textes.
2. **Références et plan visuel** : deux sites du secteur, puis couleurs, typographie et concept de mise en page.
3. **Directions** : deux ou trois variantes si la direction n'est pas fixée.
4. **Construction**, puis **vérification**, puis **livraison** avec un rapport court.

En mode revue d'un site existant, les étapes 3 et 4 sont sautées : détection, classement des problèmes par gravité, corrections demandées, nouvelle vérification.

Le détail des règles est dans [SKILL.md](../skills/site-web-sans-look-ia/SKILL.md). Un design system déjà présent dans votre projet prime sur ces règles.

## Résultat attendu

Un lien consultable, des captures desktop et mobile, et un rapport de trois ou quatre lignes (exemple dans le [README](../README.md)).
