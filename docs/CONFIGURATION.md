# Configuration

Le skill n'a aucune configuration : pas de variable d'environnement, pas de fichier de réglages, pas de clé.

Pour cette raison, le dépôt ne contient ni `.env.example` ni `SECURITY.md` : il n'y a pas de surface sensible (pas de réseau, pas de donnée utilisateur, pas de code exécuté).

## Ce que vous pouvez régler

- **Portée** : installation personnelle ou par projet ([INSTALLATION.md](INSTALLATION.md)).
- **Design system du projet** : s'il existe (CLAUDE.md, tokens, charte), il prime sur les règles du skill.
- **Outils facultatifs** : Impeccable, Playwright, serveur MCP Figma. Chacun a sa propre configuration, décrite dans sa documentation.

Voir aussi : [USAGE.md](USAGE.md).
