# Contribuer

Le dépôt ne contient qu'un fichier de règles : [skills/site-web-sans-look-ia/SKILL.md](skills/site-web-sans-look-ia/SKILL.md). Une contribution est donc une modification de texte.

## Proposer un changement

1. Ouvrez une issue qui décrit le problème : une règle fausse, périmée, trop vague, ou un cas non couvert.
2. Pour une règle de CSS ou d'outil, joignez une source officielle datée (documentation du navigateur, de la plateforme ou de l'outil). Une règle appuyée seulement sur un blog est marquée comme telle dans le texte.
3. Pour une correction, ouvrez une pull request ciblée : un sujet par pull request.

## Règles de rédaction

- Français, phrases courtes, pas de superlatifs.
- Aucun fait, chiffre ou date sans source.
- Pas de nom de projet privé ni de donnée personnelle.
- Une seule source de vérité : les règles vivent dans `SKILL.md`, les autres documents y renvoient.

## Avant d'ouvrir la pull request

- Mettez à jour [CHANGELOG.md](CHANGELOG.md) et le numéro de version en tête de `SKILL.md`.
- Vérifiez que tous les liens internes pointent vers des fichiers existants.
- Vérifiez les liens externes ajoutés.
